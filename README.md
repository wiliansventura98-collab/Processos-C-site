# Processos-C — site do painel de concursos

Site: <https://wiliansventura98-collab.github.io/Processos-C-site/>

Este repositório tem **só o código** do painel (HTML/JS, base cartográfica e banco de questões). Nenhum dado pessoal fica aqui.

Os concursos, anotações e progresso ficam no repositório **privado** `Processos-C`, no arquivo `data/concursos.json`. Ao abrir o site, entre com uma chave de acesso do GitHub (*fine-grained personal access token*) com:

- **Repository access:** Only select repositories → `Processos-C`
- **Permissions → Contents:** Read and write

A chave fica guardada só no navegador. Cada alteração feita no site é salva como um commit no repositório privado.
